# 🎵 Modern Music Player

A modern, responsive, and interactive music player built with **HTML, CSS, and JavaScript**. The project features a clean interface, playlist management, audio controls, progress seeking, volume control, and smooth visual interactions.

## ✨ Features

* 🎵 Play and pause music
* ⏮️ Previous and next track controls
* 📋 Interactive playlist
* 🔊 Volume control
* 🔇 Mute / unmute functionality
* 🎚️ Seekable progress bar
* ⏱️ Current time and duration display
* 💿 Dynamic album artwork
* 🎨 Modern and responsive user interface
* ⌨️ Keyboard-friendly controls
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** — Semantic page structure and audio interface
* **CSS3** — Responsive styling, animations, and visual design
* **JavaScript** — Audio playback, playlist functionality, controls, and UI interactions

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/bismanaz-00/modern-music-player.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd modern-music-player
```

### 3. Run the project

Open `index.html` in your browser.

No additional dependencies or installation are required.

## 🎧 How to Use

1. Click the **Play** button to start playback.
2. Use **Previous** and **Next** to switch between tracks.
3. Select a song directly from the playlist.
4. Drag the progress bar to seek through the current track.
5. Use the volume slider to adjust the audio level.
6. Use the mute button to quickly mute or restore audio.
